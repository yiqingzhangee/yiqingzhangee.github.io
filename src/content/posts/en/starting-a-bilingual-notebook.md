A personal technical site succeeds when it makes writing easier, not when it merely looks complete.

Each note begins as Markdown: content lives with code, builds are reproducible locally, and publishing is a Git push. Chinese and English are separate editorial editions—not machine-translated shadows of one another.

## A sustainable rule

Publish the language edition that is ready. When its counterpart is done, connect both through the same `translationKey`. Writing never waits for translation, while readers can always see whether another edition exists.

## Before publishing

- Make sure the title and summary state the actual question.
- Keep dates, tags, and links useful for retrieval.
- Build locally so broken pages never become public.
